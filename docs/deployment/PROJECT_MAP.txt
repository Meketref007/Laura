🚀 QUICK START FOR PRODUCTION
════════════════════════════════════════════════════════════════════════════

1. Configure credentials:
   nano /home/shopee/agente/.env
   # Add: SHOPEE_PARTNER_ID, PARTNER_KEY, SHOP_ID, ACCESS_TOKEN

2. Run quick deployment:
   bash /home/shopee/agente/deploy_production.sh

3. Deploy systemd services:
   sudo cp deploy/*.{service,timer} /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable laura_*.timer
   sudo systemctl start laura_*.timer

4. Monitor:
   sudo journalctl -u laura_* -f
   python3 -m shopee_agent.cli alerts history
